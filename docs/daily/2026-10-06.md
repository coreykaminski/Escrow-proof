# 2026-10-06: Part 1 Foundation

**Slice:** monorepo, CI, DB, API-key auth, agreement state machine, tamper-evident ledger.

## Shipped
- npm-workspaces monorepo (`packages/core`, `packages/db`, `apps/api`), TypeScript 7 strict, Biome, Vitest, GitHub Actions CI.
- Embedded Postgres (PGlite) for dev/tests, so no Docker. `DATABASE_URL=postgres://…` for real servers.
- Spec schema + hash-bound approval (an edited spec can't be approved with an old hash).
- Pure agreement state machine: 10 states, 11 events, actor permissions, deadline / appeal-window / dispute guards.
- Global hash-chained ledger: DB triggers block UPDATE/DELETE/TRUNCATE. The hash chain catches trigger bypass. Advisory lock serializes appends.
- Every transition plus its ledger entry is written in one transaction (`applyEvent`).
- REST API: platform routes (create/approve/fund/deliver/dispute/ledger), ops routes (verify/decide/resolve/settle/ledger-verify), Stripe-style idempotency, tenant isolation, test-rail-only-in-test-mode.
- CLI: `migrate`, `create-account`, `verify-ledger`.
