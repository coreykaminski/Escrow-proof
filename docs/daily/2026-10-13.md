# 2026-10-13: Integration surface (infrastructure only)

Decision: Proof Desk stays infrastructure. Platforms build their own screens on our API, SDK, MCP and A2A. Today's work makes that easy.

## 1. Embeddable verdict widget
- **Where to get it:** every report link (`POST /v1/agreements/:id/report-links`, SDK `createReportLink`) now returns `embed.html`, a script tag plus a `<div>`, and `embed.iframe_url`.
- **The loader** (`/embed/v1.js`) swaps the div for an iframe of `/embed/r/:token`, which sizes itself to fit.
  - The iframe shows the title, the outcome, who decided and when, each check's verdict, and a link to the full report.
  - Light, dark or auto theme.
- **Framing:** only `/embed/*` may be framed; every other page still sends `X-Frame-Options: DENY` and `frame-ancestors 'none'`.
  - The embed page has its own strict CSP: no form actions, scripts only from Proof Desk.
  - No documents or evidence are shown. The same expiring token as the report link is required.
- **Tests:**
  - API: snippet, framing headers, nothing private, expired link, loader served cross-origin.
  - Browser: a mock marketplace on another port embeds the widget. It renders, resizes, and opens the full report in a new tab, with no console errors.
- **Docs:** `docs/integrations/embed.md`.
